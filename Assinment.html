১. ভেক্টর ত্রিগুণন কত প্রকার ও কী কী? সংজ্ঞা

(ii) ভেক্টর ত্রিগুণন: A × (B × C) — ফলাফল একটি ভেক্টর, যা B ও C এর তলে অবস্থান করে।

৩. বিভিন্ন ভেক্টরের চিত্রসহ সংজ্ঞা

একক ভেক্টর: যে ভেক্টরের মান ১ তাকে একক ভেক্টর বলে। Â = A / |A|।
সমান ভেক্টর: যে দুটি ভেক্টরের মান ও দিক উভয়ই সমান (শুরুর বিন্দু ভিন্ন হলেও) তারা সমান ভেক্টর।
বিপরীত ভেক্টর: যে দুটি ভেক্টরের মান সমান কিন্তু দিক পরস্পর বিপরীত, তারা বিপরীত ভেক্টর। A এর বিপরীত ভেক্টর −A।
আয়ত একক ভেক্টর: পরস্পর লম্ব X, Y, Z অক্ষ বরাবর একক ভেক্টর î, ĵ, k̂ কে আয়ত একক ভেক্টর বলে। î⋅ĵ = 0, î⋅î = 1, î × ĵ = k̂।
অবস্থান ভেক্টর: মূলবিন্দু O থেকে কোনো বিন্দু P(x, y, z) এর অবস্থান যে ভেক্টর দ্বারা প্রকাশ করা হয় তা r = OP = xî + yĵ + zk̂।
সরণ ভেক্টর: কণা P থেকে Q বিন্দুতে গেলে P থেকে Q পর্যন্ত সরলরেখিক ভেক্টর PQ = rQ − rP কে সরণ ভেক্টর বলে।
শূন্য ভেক্টর: যে ভেক্টরের মান শূন্য এবং নির্দিষ্ট কোনো দিক নেই (শুরু ও শেষ বিন্দু একই) তাকে শূন্য ভেক্টর বলে, 0। যেমন: A + (−A) = 0।

৪. ভেক্টর ক্যালকুলাস কী ও প্রকারভেদ? চলক, ধ্রুবক, অপারেটর, নাবলা

ভেক্টর ক্যালকুলাস: গণিতের যে শাখায় ভেক্টর ও স্কেলার ক্ষেত্রের অন্তরীকরণ ও সমাকলন নিয়ে আলোচনা করা হয় তাকে ভেক্টর ক্যালকুলাস বলে।

প্রকারভেদ: (i) ভেক্টর অন্তরীকরণ — গ্র্যাডিয়েন্ট, ডাইভারজেন্স, কার্ল; (ii) ভেক্টর সমাকলন — রেখা, তল ও আয়তন সমাকলন।

চলক: যে রাশির মান পরিবর্তিত হয় (যেমন x, y, z, t)।
ধ্রুবক: যে রাশির মান অপরিবর্তিত থাকে (যেমন π, c, নির্দিষ্ট ভেক্টর)।
অপারেটর: যে গাণিতিক চিহ্ন কোনো ফাংশনের ওপর ক্রিয়া করে নতুন ফাংশন তৈরি করে (যেমন d/dx)।
নাবলা (∇): এটি একটি ভেক্টর অন্তরক অপারেটর।
∇ = î ∂∂x + ĵ ∂∂y + k̂ ∂∂z
এটি নিজে কোনো রাশি নয়, ক্ষেত্রের ওপর ক্রিয়া করলে অর্থ পায়। ∇φ = গ্র্যাডিয়েন্ট, ∇⋅A = ডাইভারজেন্স, ∇×A = কার্ল। ল্যাপ্লাসিয়ান: ∇² = ∇⋅∇ = ∂²/∂x² + ∂²/∂y² + ∂²/∂z²।

৫. গ্র্যাডিয়েন্ট ও এর ভৌত তাৎপর্য

সংজ্ঞা: কোনো স্কেলার ক্ষেত্র φ(x, y, z) এর ওপর ∇ ক্রিয়া করলে যে ভেক্টর পাওয়া যায় তাকে φ এর গ্র্যাডিয়েন্ট বলে।
grad φ = ∇φ = î ∂φ∂x + ĵ ∂φ∂y + k̂ ∂φ∂z

ভৌত তাৎপর্য:

  1. ∇φ এর দিক হলো যে দিকে φ এর বৃদ্ধির হার সর্বাধিক।
  2. এর মান ওই সর্বোচ্চ বৃদ্ধির হারের সমান, অর্থাৎ dφ/dn = |∇φ|।
  3. কোনো দিক â বরাবর বৃদ্ধির হার (দিকগত অন্তরক) = â ⋅ ∇φ।
  4. ∇φ সমমান তল φ = ধ্রুবক এর অভিলম্ব বরাবর কাজ করে।

উদাহরণ: তড়িৎ ক্ষেত্র E = −∇V।

৬. ডাইভারজেন্স ও এর ভৌত তাৎপর্য

সংজ্ঞা: ভেক্টর ক্ষেত্র A = Axî + Ayĵ + Azk̂ এর সাথে ∇ এর ডট গুণফলকে A এর ডাইভারজেন্স বলে।
div A = ∇⋅A = ∂Ax∂x + ∂Ay∂y + ∂Az∂z

ভৌত তাৎপর্য: ডাইভারজেন্স হলো কোনো বিন্দুর চারপাশে একক আয়তন থেকে নিট বহির্গমন ফ্লাক্স:

∇⋅A = limΔV→0 1ΔV ∮ A⋅dS
  • ∇⋅A > 0: বিন্দুটি উৎস (source), রেখা বাইরে ছড়াচ্ছে।
  • ∇⋅A < 0: বিন্দুটি শোষক (sink), রেখা ভেতরে প্রবেশ করছে।
  • ∇⋅A = 0: ক্ষেত্রটি সোলেনয়েডাল; ভেতরে যা ঢোকে বাইরে তাই বের হয়।

৮. গ্রিনের উপপাদ্য (Green's Theorem)

বিবৃতি: xy তলে কোনো সরল বদ্ধ বক্ররেখা C দ্বারা আবদ্ধ ক্ষেত্র R এবং P(x,y), Q(x,y) ও তাদের আংশিক অন্তরকসমূহ R এ সসীম ও অবিচ্ছিন্ন হলে,
∮C (P dx + Q dy) = ∬R ( ∂Q∂x − ∂P∂y ) dx dy
(C কে ঘড়ির কাঁটার বিপরীতে নেওয়া হয়।)

প্রমাণ: ধরি R এমন যে প্রতিটি অক্ষের সমান্তরাল রেখা C কে সর্বোচ্চ দুই বিন্দুতে ছেদ করে।

(i) R কে নিচের বক্র y = f₁(x) ও ওপরের বক্র y = f₂(x), a ≤ x ≤ b দ্বারা আবদ্ধ ধরলে:

∬R ∂P∂y dx dy = ∫ab ∫f₁f₂ ∂P∂y dy dx = ∫ab [P(x,f₂) − P(x,f₁)] dx
= −∫ab P(x,f₁)dx − ∫ba P(x,f₂)dx = −∮C P dx   …(১)

(ii) একইভাবে R কে বাম x = g₁(y) ও ডান x = g₂(y), c ≤ y ≤ d দ্বারা আবদ্ধ ধরলে:

∬R ∂Q∂x dx dy = ∫cd [Q(g₂,y) − Q(g₁,y)] dy = ∮C Q dy   …(২)

(২) থেকে (১) বিয়োগ করে: ∮C(P dx + Q dy) = ∬R(∂Q/∂x − ∂P/∂y) dx dy। (প্রমাণিত)

জটিল অঞ্চলকে সরল অংশে ভাগ করে একই ফল পাওয়া যায়, কারণ অভ্যন্তরীণ সীমানায় রেখা সমাকল পরস্পর কাটাকাটি হয়ে যায়।

৯. স্টোকসের উপপাদ্য (Stokes' Theorem)

বিবৃতি: কোনো বদ্ধ বক্ররেখা C দ্বারা সীমাবদ্ধ উন্মুক্ত তল S এর ওপর A এর কার্লের তল সমাকল, C বরাবর A এর রেখা সমাকলের সমান:
∮C A⋅dl = ∬S (∇×A)⋅dS = ∬S (∇×A)⋅n̂ dS
(n̂ এর দিক C এর পরিক্রমণ দিকের সাথে ডান হাতের নিয়মে সঙ্গতিপূর্ণ।)

প্রমাণ: ধরি S তলের সমীকরণ z = f(x,y), xy তলে এর প্রক্ষেপ R এবং সীমানা C′। প্রথমে শুধু Axî বিবেচনা করি।

C এর ওপর Ax(x,y,z) = Ax(x,y,f(x,y)) = g(x,y) ধরলে ∮C Ax dx = ∮C′ g dx। গ্রিনের উপপাদ্য (P = g, Q = 0) থেকে:

∮C′ g dx = −∬R ∂g∂y dx dy,    ∂g∂y = ∂Ax∂y + ∂Ax∂z ∂f∂y

তলের অভিলম্ব n̂ dS = (−fx î − fy ĵ + k̂) dx dy এবং ∇×(Axî) = (∂Ax/∂z) ĵ − (∂Ax/∂y) k̂। সুতরাং

∬S ∇×(Axî)⋅n̂ dS = ∬R ( −∂Ax∂z fy − ∂Ax∂y ) dx dy = −∬R ∂g∂y dx dy

অতএব ∮C Ax dx = ∬S ∇×(Axî)⋅n̂ dS।

অনুরূপভাবে ∮C Ay dy ও ∮C Az dz এর জন্যও প্রমাণ করা যায়। তিনটি যোগ করলে

∮C A⋅dl = ∬S (∇×A)⋅n̂ dS.  (প্রমাণিত)

১০. গাউসের ডাইভারজেন্স উপপাদ্য

বিবৃতি: কোনো বদ্ধ তল S দ্বারা আবদ্ধ আয়তন V এর ওপর A এর ডাইভারজেন্সের আয়তন সমাকল, ওই বদ্ধ তলের ওপর A এর তল সমাকলের সমান:
∯S A⋅dS = ∭V ∇⋅A dV

প্রমাণ: A = Axî + Ayĵ + Azk̂। প্রমাণ করতে হবে:

∮S (Ax dSx + Ay dSy + Az dSz) = ∭V ( ∂Ax∂x + ∂Ay∂y + ∂Az∂z ) dV

ধরি S এমন যে অক্ষের সমান্তরাল যেকোনো রেখা একে সর্বোচ্চ দুই বিন্দুতে ছেদ করে। S এর ওপরের অংশ S₂ : z = f₂(x,y), নিচের অংশ S₁ : z = f₁(x,y), xy তলে প্রক্ষেপ R।

∭V ∂Az∂z dV = ∬R ∫f₁f₂ ∂Az∂z dz dx dy = ∬R [Az(x,y,f₂) − Az(x,y,f₁)] dx dy

ওপরের তলে k̂⋅n̂ dS = +dx dy এবং নিচের তলে k̂⋅n̂ dS = −dx dy হওয়ায়

∬R Az(x,y,f₂) dx dy = ∬S₂ Azk̂⋅dS,    −∬R Az(x,y,f₁) dx dy = ∬S₁ Azk̂⋅dS
∴ ∭V (∂Az/∂z) dV = ∮S Azk̂⋅dS

একইভাবে ∭ (∂Ax/∂x) dV = ∮ Axî⋅dS এবং ∭ (∂Ay/∂y) dV = ∮ Ayĵ⋅dS। তিনটি যোগ করলে

∭V ∇⋅A dV = ∯S A⋅dS.  (প্রমাণিত)

১১. সামান্তরিক ষটফলকের আয়তন = A⋅(B×C)

ধরি ষটফলকের তিনটি সন্নিহিত ধার A, B, C।

ভূমি হিসেবে B ও C দ্বারা গঠিত সামান্তরিক নিলে এর ক্ষেত্রফল = |B×C|, এবং B×C ভূমির ওপর লম্ব। একক অভিলম্ব n̂ = (B×C) / |B×C|।
